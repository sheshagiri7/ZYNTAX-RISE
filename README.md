# ZYNTAX - RISE @ RST #5

Team workspace for RISE @ RST #5 (3-hour rapid innovation hackathon).

## Team Members & Responsibilities
- **Member 1 (Frontend / UI / UX)**: React/Frontend, Pages, UI/UX, Responsive design, Polish.
- **Member 2 (Backend / Database / APIs)**: Backend, REST APIs, Database, Auth, Business logic.
- **Member 3 (AI / Automation / Integration)**: AI features, LLM/API integration, Prompts, Agents, Intelligent workflows.

## Git Branches
- `main`: Stable production / demo branch.
- `frontend`: Frontend development.
- `backend`: Backend & API development.
- `ai`: AI, agent workflows, & model integrations.

## Setup & Guidelines
1. Copy `.env.example` to `.env` locally (never commit `.env`).
2. Add your respective API keys and configuration locally.
3. Test before merging to `main`.
